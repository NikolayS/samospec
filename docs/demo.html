$ bun src/main.ts --help
samospec: unknown command '--help'

Usage: samospec <command> [options]

Commands:
  init              Create or refresh .samo/ in the current repo.
  doctor            Diagnose CLI availability, auth, git, lock, and config.
  new <slug>        Start a new spec (persona + 5-question interview).
  resume [<slug>]   Resume an in-progress spec from state.json.
  iterate [<slug>]  Run review rounds until a stopping condition fires.
  status [<slug>]   Print phase, round, cost, wall-clock, and next action.
  publish [<slug>]  Promote to blueprints/<slug>/SPEC.md; commit, push, open PR.
  brief <slug>      Generate a summarized HTML brief — a derivative
                    summary of the published spec, NOT the spec itself.
  version           Print the samospec version and exit.

Options for `new`:
  --idea <text>
      Initial idea text (default: the <slug>).
  --force
      Archive any existing run, then start fresh.
  --skip <sections>
      Omit baseline sections from the mandatory template
      (comma-separated, case-insensitive). Valid sections:
      version header, goal, user stories, architecture,
      implementation details, tests, team, sprints, changelog.
  --max-session-wall-clock-ms <ms>
      Cap total session wall-clock (positive integer ms). Defaults to
      budget.max_session_wall_clock_minutes in config.json, or 600000
      (10 min). On cap: exit 4 with reason `session-wall-clock`.
  --verbose
      Emit per-phase and per-file diagnostics on stderr (stdout stays concise).
  --yes, --accept-persona
      Skip the persona-proposal readline prompt.
  --answers-file <path>
      Load 5-question interview answers from JSON
      (`{ "answers": [s, s, s, s, s] }`). One of --yes, --accept-persona,
      or --answers-file is required when stdin is not a TTY (#114).
  --interview-protocol jsonl
      Drive the interview over stdin/stdout using line-delimited JSON
      events. Stdout emits one JSON object per line:
      `{"type":"persona-proposal"…}`, `{"type":"question","id","text","options"}`, `{"type":"complete"}`.
      Stdin consumes `{"type":"persona-answer","kind":"accept"|"edit"|"replace"}`
      and `{"type":"answer","id","choice","custom"?}`. Human-facing
      status messages route to stderr. Bypasses the non-TTY refusal
      (the protocol IS the non-TTY driver). For UI wrappers / CI.

Options for `iterate`:
  --rounds <N>
      Cap the number of review rounds this session.
  --no-push
      Don't push round commits to the remote.
  --remote <name>
      Git remote name (default: origin).
  --quiet
      Suppress per-phase progress + heartbeat (default: verbose on stderr).
  --verbose
      Alias / no-op — iterate is verbose by default (see --quiet).
  --max-session-wall-clock-ms <ms>
      Cap the review-loop session wall-clock (positive integer ms). On cap:
      exit 4 with reason `session-wall-clock`.
  --on-dirty <incorporate|overwrite|abort>
      Answer the uncommitted-edits prompt without reading stdin. Required
      when stdin is not a TTY and `.samo/spec/<slug>/` has dirty edits (#114).
  --push-consent <yes|no>
      Answer the first-push consent prompt without reading stdin. Required
      when stdin is not a TTY and the remote has no persisted consent (#136).
  --yes
      Accept everything non-interactively; implies --push-consent yes.

Options for `publish`:
  --no-lint
      Skip the publish-time lint pass.
  --remote <name>
      Git remote name (default: origin).

Options for `brief`:
  --out <path>
      Override the output path. Repo-relative or absolute.
